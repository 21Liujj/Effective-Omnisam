# OmniSAM Paper v1.1 CN

## Overleaf settings

- Main document: `main.tex`
- Compiler: `XeLaTeX`
- Bibliography: BibTeX
- Bibliography database: `refs.bib`

## Compile

1. Upload the complete zip as a new Overleaf project.
2. Open project settings.
3. Set the compiler to XeLaTeX.
4. Confirm the main document is `main.tex`.
5. Click Recompile.
6. If citation numbers initially display as `?`, clear cached files or recompile again.
